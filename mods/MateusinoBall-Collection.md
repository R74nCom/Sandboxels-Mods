# Sandboxels-Mod — Mods by Mateusino Ball

A comprehensive collection of JavaScript-based mods for Sandboxels, the in-browser falling-sand simulator.

## Repository

**GitHub:** https://github.com/MateusinoBall/Sandboxels-Mod

**Description:** Sandboxels Mods by Mateusino Ball.

**Language:** JavaScript (100%)

## About This Collection

This repository contains several JavaScript-based mods designed to enhance and extend the Sandboxels experience. Each mod is carefully crafted and tested for compatibility.

## How to Install

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MateusinoBall/Sandboxels-Mod
   ```

2. **Follow the README:** Navigate to the cloned directory and follow the installation instructions in the README.md file.

3. **Load mods into Sandboxels:** Use the Mod Manager in Sandboxels to load and enable the mods.
